## 해결된 이슈

### ISS-001: Railway 502 (Python 감지)
- **증상**: 빌드 성공하지만 502 응답
- **원인**: taieng 레포의 `naver_monitor.py`가 Nixpacks를 Python 모드로 전환 → `python naver_monitor.py` 실행 → 빈 파일이라 즉시 종료
- **해결**: 전용 레포 `45cm-mkt` 분리 + Dockerfile 사용

### ISS-002: Supabase 스키마 미노출
- **증상**: `PGRST106 Invalid schema: marketing`
- **원인**: PostgREST에 marketing/core_ai 스키마 미등록
- **해결**: `ALTER ROLE authenticator SET pgrst.db_schemas` + `NOTIFY pgrst, 'reload schema'`

### ISS-003: OpenAI 호출 hang
- **증상**: `/draft/generate` 무한 대기
- **원인 1**: REDIS_URL 미설정 → BullMQ가 localhost:6379 연결 시도 → hang
- **원인 2**: 이전 코드에 AbortController/timeout 미적용
- **해결**: REDIS_URL 환경변수 추가 + 30초 AbortController 타임아웃

### ISS-004: Redis MISCONF
- **증상**: `MISCONF Redis is configured to save RDB snapshots...`
- **원인**: Redis 볼륨 디스크 쓰기 실패
- **해결**: Redis 서비스 재시작 후 자동 복구

### ISS-005: CTA subject_id 타입 오류
- **증상**: `GET /c/:ctaId` 500 에러
- **원인**: `analytics_events.subject_id`가 UUID 타입인데 문자열(`free-diagnosis`) 전달
- **해결**: `ALTER TABLE` → text 타입으로 변경

## 남은 이슈

### OPEN-001: Humanize Worker 검증
- **상태**: BullMQ 큐에 등록은 확인, Worker 소비 및 humanized_body 저장은 Railway Logs에서 확인 필요
- **우선순위**: P1

### OPEN-002: Slack Callback 등록
- **상태**: `/approval/callback` 엔드포인트 구현됨, Slack App Interactivity URL 등록 필요
- **작업**: Slack App → Interactivity & Shortcuts → Request URL → `https://api.45cm.com/approval/callback`
- **우선순위**: P1

### OPEN-003: Redis 안정성
- **상태**: MISCONF 에러 간헐 발생
- **원인**: 볼륨 디스크 이슈 (Railway Redis)
- **대응**: `stop-writes-on-bgsave-error no` 설정 검토 또는 Redis 볼륨 확장
- **우선순위**: P2

### OPEN-004: Classify Worker 미구현
- **상태**: collect → classify 큐 등록하지만 consumer 없음
- **우선순위**: P3 (다음 스프린트)

### OPEN-005: Vuexy Admin Dashboard 배포
- **상태**: `app.45cm.com` 대시보드 미배포
- **작업**: Vercel에 Vuexy Next.js 템플릿 배포 필요
